# Semana 2 — Catálogo e interacción

Catálogo de platos bolivianos de referencia, categorías, búsqueda, selección de cantidades, favoritos locales y formulario de solicitud de cotización.

## Archivos principales
La versión funcional y actualizada está en la raíz del proyecto. Esta carpeta documenta la etapa y evita duplicar HTML, CSS o JavaScript.

- `../../index.html` — aplicación responsiva única para celular y computadora.
- `../../css/styles.css` — estilos y adaptación por tamaños de pantalla.
- `../../js/app.js` — interacciones y cotizador.
- `../../json/platos.json` — platos de referencia con imágenes asociadas.
